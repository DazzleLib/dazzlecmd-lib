## Caveats

- A kill proves the suite noticed *this* change, not that it tests the right thing.
- **A clean sweep is evidence about the mutations tried, not proof of suite completeness.**
- POSIX rename semantics were simulated on Windows (`os.replace`, and a directory variant that replaces an empty target). The suite has not yet run natively under WSL for this change.
