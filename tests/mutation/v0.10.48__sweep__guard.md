## Caveats

A kill proves the suite noticed *this* change, not that it tests the right thing -- and **a clean sweep is evidence about the mutations tried, not proof of suite completeness.** Twelve mutants over a 2,240-line module sample the deciding code only; the lexer, the analyser and the table's forms were not mutated here (the table's forms are covered by each form's own examples, which the test file runs).
